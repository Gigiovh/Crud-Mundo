## 🌍 CRUD-Mundo

Projeto desenvolvido na disciplina Desenvolvimento Web, com o objetivo de aplicar conceitos práticos de construção de páginas e manipulação de dados utilizando HTML, CSS e JavaScript.

O sistema permite gerenciar informações de países e das cidades vinculadas a cada um deles. Na página inicial, o usuário encontra algumas informações gerais sobre países. Já pelo menu, é possível acessar todos os países cadastrados e visualizar as cidades relacionadas, além de adicionar novas cidades, editar ou excluir as existentes.

## 🌐 APIs Utilizadas

| API | Finalidade |
|------|-------------|
| **REST Countries** | Obter informações sobre países |
| **OpenWeatherMap** | Consultar informações climáticas das cidades |

---

## 📌 Funcionalidades

- Página inicial com informações gerais sobre países  
- Visualização de países e suas cidades cadastradas  
- Cadastro de novas cidades  
- Edição de cidades já registradas  
- Exclusão de cidades
